Habit Dashboard Privacy Policy

Last updated: March 29, 2026

Habit Dashboard is a local-first habit tracker. This release does not require you to create an account or sign in before using the app.

What data the app stores
- Habit titles, categories, and habit settings you create.
- Completion history, skips, slips, streaks, milestones, and notes you enter.
- Reminder preferences, onboarding status, theme choice, and dashboard preferences.
- Backup files that you explicitly export or import.

How data is used
- Your data is used only to run habit tracking features, reminders, analytics, backup, restore, and export flows inside the app.
- The app is not designed to sell personal data.
- The main habit data in this release is stored locally on your device.

Notifications
- If you enable reminders, notification settings and reminder content are stored locally so the app can schedule notifications on your device.

Backups and exports
- If you export a backup file or copy backup data, that exported data is under your control.
- Imported backups replace or merge local app data depending on the restore flow you choose.

Third-party services
- The project may include Firebase configuration files and authentication code for future versions, but login is not required for this release flow.
- The app may rely on platform or Flutter services needed for local storage, notifications, and file picking.
- This release is not designed to upload your habit history to a remote server as part of the normal user flow.

Your control
- You can edit, archive, delete, export, import, or reset your local data from inside the app.
- You can disable reminders at any time.
